# Agent Nexus Hub 🛸

**Agent Nexus Hub** is an AI Conversation Control Tower designed for enterprise-grade management of AI agents, conversational flows, and multi-tenant SaaS operations.

## 🚀 Overview

The platform provides a centralized dashboard to:
- **Manage AI Agents**: Configure lifecycle stages, risk levels, and autonomy caps.
- **Orchestrate Conversational Flows**: Define journey contracts for AI and Human interaction.
- **Monitor Consumption**: Track token usage, message volume, and costs per tenant.
- **Audit & Compliance**: Maintain logs of all agent activities and security assessments.
- **Integration Hub**: Seamlessly connect with N8N and voice providers like Retell AI.

## 🛠️ Technology Stack

- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Icons**: Lucide React
- **Architecture**: Multi-tenant SaaS with ISO 42001 governance principles.

## 💻 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:8080`.
