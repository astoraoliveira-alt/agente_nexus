
--- PAGE 1 ---
Provides a set of endpoints that allow partners to simulate, submit, and retrieve loan requests.
These endpoints enable integration with the Clover Capital loan system, offering functionality to
preview loan terms, initiate funding requests, and track the status of existing loan requests.
Base endpoint
All API requests must be directed to one of the following base URL’s
EnvironmentURL
Production https://api.moneymoneyinvest.com.br
Sandbox https://apidev.moneymoneyinvest.com.br
This base endpoint serves as the root for accessing all available API resources. Ensure that all
requests are properly formatted and authenticated according to the API documentation.
🔒  Authentication
The API uses JWT (JSON Web Token) for secure authentication.
During the integration process, partners must provide a previously registered email and
password. Using these credentials, the partner can authenticate by calling the appropriate
login endpoint to obtain an token.
This token must be included in the Authorization header of all subsequent requests to access
protected endpoints like so:
Ensure that the token is stored securely and refreshed as needed according to the token
expiration policy.

National Registry of Legal Entities) number. This endpoint allows partners to query and access
information related to a previously submitted loan request, using the CNPJ as a unique
identifier.

Webhook - Status Change Notification
Whenever the status of a loan request changes, the system automatically sends a webhook
notification to the partner's registered endpoint via an HTTP POST request.
This allows partners to receive real-time updates about the lifecycle of their loan requests
without the need to poll the API.
Configuration
During the integration process, the partner must provide a webhook URL where notifications
will be
delivered. This URL is registered internally and associated with the partner's account.
